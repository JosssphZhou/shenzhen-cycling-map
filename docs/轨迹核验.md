# 轨迹核验与导出边界

核对日期：2026年10月8日。本轮完成8条连续轨迹，另保留33项全市路线资料。8条轨迹全部来自开放地图的实际道路节点，共5093个轨迹点，没有绘制地标连接直线，没有平滑或移动坐标。

产品场景已改为按地标组织的抽象微缩示意。场景中的摆放、缩放和示意连线与本文件记录的真实轨迹分开；GPX继续使用原始WGS84坐标，不能从微缩场景反算路线。

“已核对路网”表示已核对公开路网中的原始节点、连接关系、通行方向和已标出的禁行属性，并对照政府公布的骑行用途与管理条件。它不表示现场复骑、当日畅通或逐点路面测量。页面与轨迹文件均保留这一界限。

## 通行依据与仍存在的边界

- [深圳湾公园管理方2025年3月20日答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3115634)是单车准入依据；现场骑行标识和人流管理仍适用。“全时段单车准入”没有被扩写成各管理区域24小时开放。
- [大沙河管理方2026年8月13日答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3487097&via=pc)明确东岸全天可骑、西岸周末和节假日禁骑。当前轨迹尚未被确认是全程东岸，因此使用工作日限定。路网中的市政单行方向继续保留，没有因为绿道可以双向骑行就反转机动车道路。
- [梧桐绿道2024年12月10日管理答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3047480&via=pc)给出莲塘管理站至芦雁桥约3公里段的自有自行车限制；新轨迹不是深圳水库完整环线。梧桐的骑行用途另见[2026年官方介绍](https://www.szlh.gov.cn/lhlh/zjlh/lhss/bcss/jpld/wtld/content/post_12936807.html)。
- 西丽湖依据[2026年1月主线指引](https://www.szns.gov.cn/mlns/stns/lc/ldbd/content/post_12599272.html)，保留06:00至22:00与周末共享单车限制；[2026年4月水库管理提醒](https://www.szns.gov.cn/xxgk/qzfxxgkml/bmdt/content/post_12714401.html)中的大坝禁自行车区域未接入。
- 盐田依据[2026年7月15日升级贯通公告](https://www.yantian.gov.cn/cn/zjyt/jjyt/bmxx/content/post_12894163.html)及具体骑行道路标签。公告中的19.5公里属于整体路线说明，不能直接替代可导出几何。
- 石岩湖开放条件依据[2026年官方问答](https://www.sz.gov.cn/ztfw/gysy/wyw_183970/ywzsk_184570/content/post_12660971.html)。没有用过去30.8公里的绿道总长来填轨迹长度。
- 银湖山骑行用途有[2026年罗湖区资料](https://www.szlh.gov.cn/zwfw/ztzq/gylhlcdbdaysdtx2026ngjdarxszl/stcq/content/post_12804783.html)支持。共享单车新规则仍未取得，因此仅按自有车收录；不把山腰骑行线与登顶郊野径混用。

没有把普通道路一概排除：梧桐、大沙河、西丽湖等线路保留官方骑行范围及开放地图骑行关系中的必要市政接驳。也没有把“机动车能通行”当作自行车通行的充分条件。步道缺少自行车依据、明确禁入、台阶或施工等情况均不用于本轮导出。

## 盐田完整关系为什么不直接导出

已匿名取得[完整关系19559465](https://api.openstreetmap.org/api/0.6/relation/19559465/full.json)：80条道路、903个节点，关系版本8，更新时间2026年8月14日。按节点连接检查后，它存在3个断开的连通分量，并含深盐路主干道、进港道路和支线。即使所有被引用节点都齐全，也不表示路线连续。

本轮只选取其中从节点6944688370至14022833226的连续自行车道。每条边必须来自同一OSM道路里相邻的两个节点；没有跨越断点连接两个坐标。完整盐田海岸仍作为19.5公里资料候选保留，禁止导出。

## 全市资料候选

33项资料来自[路线调研](路线调研.md)。22项有明确对应范围的公开参考里程，数字可参与距离筛选，旁边保留来源口径。工程总长、双岸长度、含支线的景区总长与规划长度存在歧义时继续留空，不能为了筛选填造精确值。

候选只显示有来源的地点定位，没有绘制线路。定位来源是开放地图实际具名对象，具体对象编号保存在`public/data/routes-evidence.json`。对人才公园、南澳新东路、银湖山、凤凰公园等同名地点已人工检查，避免定位到其他城区的同名对象。定位点可能是相关入口、公园或道路上的代表点，不承诺是自行车出入口。

环深圳水库南线仍需单独核对2025年底新连接线；不能仅因为东湖与淘金山各自存在坐标，就把二者连成直线。福田河有台阶与权限标签冲突，完整线未开放导出。大鹏鹿嘴有新旧通行资料冲突，未接入新东路线。光明观湖云桥明确禁止自行车进入，未生成跨桥骑行轨迹。

## 数据与可重复检查

- 开放路网来自[Geofabrik广东数据](https://download.geofabrik.de/asia/china/guangdong.html)，下载于2026年10月8日，PBF头部时间为2026年10月6日20:21:06 UTC。
- 开放地图数据按[ODbL许可](https://www.openstreetmap.org/copyright)使用；原始坐标、道路标签和衍生路线数据库保留开放地图贡献者署名与许可说明。许可是数据使用依据，不等于道路准入证明。
- `scripts/routes-extract.py`提取节点编号、完整坐标、道路标签与骑行关系；不会用渲染时简化的城市道路反向生成轨迹。
- `scripts/routes-selections.json`保留逐条选线的关系编号、实际起终节点、可用道路集合与审核说明。
- `scripts/routes-build.py`只在已选的真实道路图中按节点寻找连续路径，遵守单行标签；不允许断点吸附或补线。
- `public/data/routes-evidence.json`保存每条轨迹的原始节点序列、逐边道路编号、坐标和道路标签，离线即可复核连续性。
- `lib/gpx.ts`与`scripts/routes-gpx.mjs`使用同一导出函数。坐标顺序保持WGS84原值；待核路线、断开的多段几何、无效坐标或距离不一致均拒绝导出。

离线检查：

```sh
npm run check:data
```

重新获取开放路网后，先安装`osmium`，用缓存目录作为参数：

```sh
python3 scripts/routes-extract.py /缓存/guangdong-latest.osm.pbf /缓存/routes-osm.json
python3 scripts/routes-build.py /缓存
node scripts/routes-gpx.mjs
npm run check:data
```

数据更新可能改变道路编号、端点或权限；脚本报错时必须重新核对选线，不能通过放宽禁行或连接条件来维持导出数量。

## 本轮实际验证

2026年10月8日执行`check-data.mjs`通过：41项资料、8条连续轨迹、5093个原始点。检查包含坐标范围、原始节点一致性、每条边来自实际道路相邻节点、禁行属性、方向、来源日期、距离计算、静态GPX与网页导出函数一致性。

另用Python标准XML解析器实际读取8份GPX，轨迹点数与原始几何完全一致。反例检查覆盖33条候选禁止导出，以及无效坐标、断开的多段轨迹和错误距离。这些验证证明数据与导出实现的一致性，不替代现场骑行、真实码表导入或手机性能验证。

补充完成示意与真实轨迹的分离检查：实际调用`diagramForRoute`后，8条示意线均保持开口，33条候选均不生成示意线路，全部原始路线对象保持不变。场景只读取示意点，网页GPX导出仍只读取`route.geometry`；重新执行数据校验和8份GPX逐点回读均通过。大沙河为南向北，西丽东岸与梧桐保持非环线。石岩湖示意缺口两端的相对摆放问题已由场景负责人修复，复核起点为[131.576,-134.446]、终点为[108.424,-134.446]，均处于湖北侧，起东终西并保留开口；真实GPX从未受此示意修改影响。

地区映射另做函数级检查：41项均能匹配已有地区，不再因为“大鹏”与“大鹏新区”名称不同而回退深圳湾；葵涌海岸、新东路、海贝湾3项候选均已映射至大鹏场景。银湖山候选曾因跨区匹配顺序先命中福田；现已按银湖山专题匹配罗湖，使用与已导出条目一致的山体范围和锚点。候选仍不生成示意线路。
