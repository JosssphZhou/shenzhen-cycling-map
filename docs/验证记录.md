# 本地验证记录

日期：2026年10月8日。当前交付为本地运行的中文微缩骑行地图，未发布到互联网。

## 方向修正

按最新反馈，场景以地标和手工编排的微缩街区表达深圳。春笋、春茧、人才公园与海岸串起深圳湾路线；其他片区围绕各自地标、山体和湖泊组织。普通街区、山海及区际距离经过压缩，画面不采用统一地理比例。

全城由106个建筑与地标模型及成组树木、街道组成，主要复用原作构造器。原先整城建筑、地形与分片方案已退出运行时，相关代码和研究材料归档至本任务工作目录。页面真实请求记录中没有城市建筑、地形或分片数据请求，`public/` 资料合计约908 KB。屏幕示意与真实轨迹独立。

## 构建与数据

- 队列生产构建通过，包含 TypeScript 检查与静态页面生成。静态输出可由普通 HTTP 服务器运行。
- 数据检查通过：41项资料、8条连续轨迹、5093个原始坐标；33项候选不允许导出。
- 检查覆盖连续性、道路节点来源、方向、距离、无效坐标、多段断线、来源日期与 GPX 一致性。
- 从实际页面点击导出深圳湾 GPX，并用 XML 解析器回读。686个轨迹点逐点等于原始数据，没有将微缩坐标或虚构高程写入文件。
- 8条示意均为开口线。大沙河北行、西丽东岸非环线、石岩湖北侧缺口及起东终西关系均已核对。示意函数不会修改原始路线对象。
- 原 Factory 仓库仍位于版本 `148758ae19a9b2201245485bf3619ab5e742f8f4`，工作树无改动，3700服务保留。

构建日志：[构建.txt](验证证据/构建.txt)。数据日志：[数据校验.txt](验证证据/数据校验.txt)。页面实际下载：[深圳湾轨迹](验证证据/深圳湾-页面实际下载.gpx)。

## 浏览器实际操作

使用 Ego Lite 在同一任务空间操作本地页面，并回看截图。

| 操作 | 实际结果 |
| --- | --- |
| 打开深圳湾首屏、选中骑行路线 | 三维场景、地标、路线详情正常显示 |
| 分享路线 | 复制包含路线参数的本地链接；带参数直达页面能恢复所选路线 |
| 大沙河选择周末与节假日 | 显示禁骑提醒，禁用导出；改回工作日恢复 |
| 选择尚未核验的大鹏候选 | 展示资料，导出按钮禁用 |
| 搜索不存在的路线 | 显示空结果；重置后恢复41项资料 |
| 打开无效路线链接 | 显示中文提示，不创建虚假路线详情 |
| 全城按钮与视图工具 | 清除所选路线，同步全城标题与镜头；点击地标可重新靠近 |
| 明暗主题、时间、天气、暂停 | 界面状态和场景随操作变化，夜间地标窗格亮起，雨线显示 |
| 资料与致谢 | 对话框正常打开、关闭，显示原作与数据来源 |
| 主动模拟 WebGL 上下文丢失 | 显示错误和重试入口，路线详情与导出仍可用；重试恢复后仅保留一个画布 |
| 手机浏览器尺寸 | 实测390×843及429×928 CSS像素，无横向溢出；地图与可滚动详情分区显示，导出入口保留 |
| 生产静态输出 | 使用独立本地静态服务器打开，路线参数、场景和详情正常加载 |

追加组景后，浏览器曾捕获一次初始化异常：新增草坪将填充材质名`grass`传入原作`Part.box`的配色组合参数。现已改为原作支持的`gs`，并重新运行浏览器场景初始化、全城视图和近景检查。原作代码保持原样。

## 尚未验证的范围

手机检查使用桌面浏览器的窄屏与设备模拟，不等同于真实手机的触摸、性能或文件分享验证。未做实地复骑、真实码表导入，也未验证各路段当日临时开放状态。累计爬升缺少可靠数据，全部保留待核。33项候选只有公开资料，不能因画面中出现地标就视作已核验路线。

页面的交通、天气和时间均为场景模拟。视觉是否达到用户期望，仍由用户查看运行画面判断。
