# 外卖专注体验原型

本轮验证：用户专注时，一位骑手在真实深圳地图上自动送单，能否产生持续陪伴、打工得失与城市探索的体验。

这是独立试玩页面，使用既有 Next.js 项目、Factory 界面样式、字体、深圳建筑与地形。存放在 `prototype/shenzhen-delivery-focus` 分支，不替换原有骑行选线入口。页面路径为 `/prototype/delivery/`。

## 已确认规则

- 用户选择专注时间，系统动态安排连续配送行程；45分钟至少安排两单。
- 系统自动派单、规划路线、处理模拟中的等餐、天气与路况事件。专注期间没有必须响应的操作。
- 收入、超时扣费与评分有得失；模拟事件不延长用户设定的专注计时。
- 下一趟从上次收工位置继续。主动提前收工结算已完成订单，取消未完成订单并影响评分。
- 关闭页面不会终止配送；以持久化的开始时间和真实经过时间恢复进度，完成后只结算一次。
- 收入用于车辆、装备和住处；配送足迹用于探索片区、地标和熟客记录。
- 订单与经济均为虚构游戏数据，深圳地图与可行走路网复用现有来源。
- 正常专注使用实际分钟；快速试玩明确标注加速，并使用独立试玩存档。

## 模块边界

1. `lib/delivery/`：道路寻路、配送计划、时间派生进度、本地存档、幂等结算和消费。依赖真实时间戳，不依赖网页是否保持打开。
2. `scene/delivery.ts`：消费 `DeliverySceneState`，复用原作模型和材质绘制外卖骑手、餐箱、路线、取送点；不拥有计时和钱包。
3. `components/DeliveryPrototype.tsx`：同一画框内的开工、当前订单、结算、养成和探索。沿用 Factory 导航、控件、卡片及字体。

先比较“每帧累计计时”与“持久化时间戳派生行程”两种方案。本轮选择后者：网页关闭后无需后台进程仍可恢复；事件和订单结果在生成时固定，刷新不会重新掷骰子。正常存档与试玩存档各自拥有唯一活动行程，重复恢复不会重复奖励。

## 验证目标

在实际浏览器从开工走到结算并购买装备；检查45分钟订单数、路线连续性、关闭后恢复、重复刷新不重复结算、提前收工与下一趟位置延续。回看桌面及手机尺寸截图，复查原骑行入口。原型不新增测试套件，所有实际结果与未验证项在本文件末尾补记。

## 本轮实现范围

2026年10月26日，原型使用全深圳三维城市画面，首轮可配送道路集中在后海、深圳湾、科技园、南头、蛇口、前海及附近街区。路网由工作区留存的原始OSM道路节点提取，保留99,339个节点、111,542条连接与95个虚构取送点，输出4,504,232字节。订单只沿来源道路连接，原型不判定完整现实通行许可。

专注时长可选5至180分钟，45分钟安排两单。90秒试跑浓缩45分钟，使用独立存档。首趟包含等餐超时，收入仍足以购入第一件保温餐箱。保温餐箱和雨衣减少对应事件扣费，车辆提高后续配送费，绿植改变住处小图。近期账单保留8趟，钱包、总专注时长、配送总数、已探索片区、地标与熟客记录持续累计。

配送按真实开始时间派生位置、订单和结算，不依赖网页常驻。订单计划与模拟事件在开工时固定，刷新不重新生成。存档事务使用同源Web Locks串行处理，结算后移除活动行程；正常专注与试玩分开保存。只暂停城市动画或快进城市时刻不会改变专注计时。

## 本机验证

- 生产构建及其TypeScript检查通过。旧 `.next` 中的重复生成文件造成首轮独立类型检查冲突，旧缓存已移至任务工作目录留存，重新生成后独立类型检查通过。
- 直接调用真实领域入口，检查5、25、45、90、180分钟计划。订单数分别为1、1、2、5、10；本次45分钟样本总路长7.536公里。逐段比对实际网络连接，非来源道路连接为0。检查了重复结算、第一件装备购买、提前结束保留已送订单及下一趟精确接续位置。
- Ego Lite任务空间22实际打开生产静态输出，完成正常45分钟开工与独立90秒试跑。试跑中关闭页面，44秒后重新打开自动结算两单，实收20.78元，含4.03元超时扣费；购买12元保温餐箱后余额8.78元。刷新后余额、装备和账单数保持不变。
- 下一趟起点与上一趟终点一致，足迹记录可看到后海、南头、春茧与熟悉的小店。正常专注提前结束后取消未完成订单并降低评分。
- 在429×928手机尺寸实际点击暂停城市动画，卡片与底部配送条均可见，无横向溢出；城市时刻停下后配送仍继续。已回看手机和桌面图片。
- 注入配送路网503错误后开工按钮禁用并显示中文重试；撤销注入后实际点击重新载入，开工恢复可用，保持一个canvas。
- 长地址、空订单、存档错误和提前结算的卡片状态已在组件状态页回看。

原型没有新增测试套件，以上包含实际入口操作、直接领域调用及设备尺寸模拟。没有实地配送、真实外卖订单、正式运营收入或真实手机性能验证。外网首次加载未验证，本轮不公开发布。城市探索目前以片区、地标、熟客和近期配送记录呈现，完整街坊剧情仍待后续设计。

补充验证：城市动画保持暂停时，后续90秒试跑仍继续推进；在完成一单后主动提前结束，账单保留一单收入、取消一单，评分相应下降。原骑行入口也已在最终生产输出实际打开，深圳湾选择与“查看、导出、更多”保留，不创建配送图层。

用词检查已执行。“派单”“收工”命中通用用词表，但它们是用户确认的游戏领域词，按本任务语境保留。最终仅修正选中骑手时重复显示的标签，并重新构建与回看，未改变计时或结算规则。
