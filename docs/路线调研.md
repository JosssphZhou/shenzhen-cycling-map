# 深圳骑行地图路线调研

查证日期：2026年10月8日。

这张地图首先帮助骑行者出发前选路线。城市按真实地理构建，视觉直接对齐 factory 的等距细线与灰阶风格，全部使用中文。普通建筑按真实位置和轮廓简化，地标精细制作，保留车流、行人、列车、港口船舶及昼夜天气动态。这些是已确认的产品决定。

本轮整理33项路线及候选，覆盖南山、福田、罗湖、盐田、宝安、光明、龙华、龙岗、坪山和大鹏。深汕特别合作区不在此次连片深圳地图范围内。清单用于建立路线库，不声称包含每一条可骑街道，也不代表当天全部畅通。

## 可以先做哪些路线

优先核准深圳湾、大沙河、盐田海岸、梧桐与环深圳水库南线，再补环石岩湖、观澜河、光明湖、龙岗河、大山陂和大鹏海岸。这些区域已有较清楚的官方骑行依据，既覆盖用户最关心的地点，也能呈现海岸、河流、水库和山林的不同体验。最终上线顺序仍待产品对齐。

本轮已取得路线用途、沿线节点和部分限制的公开证据。尚未取得所有路线的精确坐标、逐段现状和可靠爬升数据。不能用地标直线或工程总长代替真实骑行路线。

## 不应直接画成可骑路线的部分

- 深圳水库北侧工程含郊野径，完整环库需要核准每段；不能直接画一圈并填入规划里程。依据见环库路线。
- 光明观湖云桥明确禁自行车，不能用“下车推行”代替“不得带车进入”。依据见光明湖路线。
- 虹桥与大顶岭的周末规则仍需核实；近期骑行宣传不能自动视作取消旧限制。依据见虹桥路线。
- 杨梅坑至鹿嘴的通行资料有冲突，暂缓作为连续可骑延长线。依据见新东路路线。
- 东西涌沿海穿越属于徒步路线，不作为自行车连接线。[市政府介绍，2024年4月](https://www.sz.gov.cn/cn/xxgk/zfxxgj/tpxw/content/post_11274201.html)
- 阳台山登山环线与骑行绿道不同，不能因名称相似合并。依据见阳台山路线。
- 茅洲河宝安全段、立新湖、凤凰山、龙城、三洲田及盐三路等继续作为补证候选；本轮未达到完整路段规则与线位均已核准的程度。

## 地图怎样帮助骑前选线

以下为调研形成的产品建议，尚未全部确认。

每条路线至少展示起终点、单程或环线、距离、累计爬升、路面、途经点、补给与厕所、开放时段，以及自有车和共享单车的区别。尚无可靠证据的字段显示“待核实”，不编填数字。

用户选择日期和车种后，地图应提示沿途不适用的路段。针对限制分别使用“禁止骑行”“禁止自行车进入”“需要推行”“限时开放”“通行待核实”，不把这些状态合并。

真实路线应与真实道路匹配，保存路段来源和核实日期。路线卡距离按核准的几何计算，爬升按可靠高程计算；在完成之前，官方公布的参考长度应明确标注口径。画面里的车辆和天气属于视觉演示，不能伪装成实时交通与天气数据。

全市管理规定自2026年8月1日起实施，公园、水库等的开放时间依场地管理单位执行；极端天气、活动与人流高峰可能调整通行。因此，静态路线资料需要保留管理方公告入口。[市城管局《深圳市休闲骑行道管理规定（试行）》](https://cgj.sz.gov.cn/zwgk/gfxwjcx/content/post_12977504.html)

## 待补的真实地图数据

公开规划与路线介绍足以确认候选和部分条件，尚不能直接生成可靠骑行轨迹。下一步需要获取可使用的道路、建筑、地形和路线坐标，逐段核对岸别、出入口、过桥、台阶及断点。没有精确轨迹前不生成供实际出行使用的轨迹文件。

2025年的市级专项规划包含未来建设目标；规划线与已开放线必须分开显示。[市城管局规划通告](https://cgj.sz.gov.cn/ydmh/ydghjh/content/post_12109263.html)
