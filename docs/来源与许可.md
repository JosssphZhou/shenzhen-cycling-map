# 来源与许可

核对日期：2026年10月8日。本仓库用于本地开发，未公开发布。

## 原作代码与视觉

参考 [Khalidabdi1/factory](https://github.com/Khalidabdi1/factory)，固定版本 `148758ae19a9b2201245485bf3619ab5e742f8f4`。本地原仓库和服务保持不动。

按用户要求，适用的内核、材质、基础样式与模型直接复用。`app/factory.css` 原样复制自原作 `app/globals.css`，中文排版与骑行功能在独立文件中适配。其他复用模块、必要适配与哈希在渲染说明中记录。

原作当前未提供 Factory 本体许可证。README 中的 MIT 说明分别适用于 ai-iso-skill（© Tolga Cohce）与 Three.js（© Three.js authors），不能作为整个 Factory 的许可。公开分发之前需要核实原作授权，本仓库不擅自将整个改编标记为 MIT。

## 真实骑行轨迹

© OpenStreetMap 贡献者。采用[开放数据库许可](https://www.openstreetmap.org/copyright)。路线来自实际道路节点，提取范围、方向、连续性和通行依据保存在轨迹核验文档及数据证据中。

地图中存在一条道路，不单独构成骑行许可。路线另行对照政府与管理方资料。页面保留每条路线的来源、发布和核实日期。

## 微缩场景

场景不是逐栋、等比例的地理数据复刻。深圳地标根据其可识别形态建模，普通楼群、道路、树林和山海经过艺术编排；模型中的比例、位置和屏幕路线不能作为测量或导航数据。

此前研究下载的Overture建筑与Copernicus高程已退出运行时和页面静态资源，相关来源记录保存在工作区研究档案中。当前页面不加载这些全城数据。
