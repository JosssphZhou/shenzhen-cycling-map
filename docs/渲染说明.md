# 深圳三维地图渲染说明

## 视觉来源

参考仓库为 [Factory](https://github.com/Khalidabdi1/factory)，参考版本为 `148758ae19a9b2201245485bf3619ab5e742f8f4`。

本项目直接保留原作可迁移的内核、材质和动态模型。深圳地理底图、深圳地标、实际骑行轨迹与路线镜头是新增部分。镜头保持固定等角正交投影，面材质不受光照影响，模型轮廓线固定为 1 CSS 像素，镜头缓动沿用原参数。原作当前未提供明确的项目本体许可证，不能将整个 Factory 宣称为 MIT 项目。其 README 对 ai-iso-skill 与 Three.js 的 MIT 说明只适用于相应来源。当前实现用于本地开发，公开分发前须明确相关授权。

## 恢复早期三维城市

当前画面以2026年10月8日早期真实三维城市为基线。建筑与地形来自原始归档，保留街区密度、建筑轮廓及楼高差异。页面仍使用已经迁移的Factory画框、工具、卡片和交互。

`public/data/shenzhen-city.json`保存城市概览、真实路网、水体、海岸、区界、建筑概览与高程采样；详细建筑和细路按视野从`public/data/tiles/`加载。`city-terrain.json`保存已按海岸裁切的地形三角网。源数据目录继续原样保留，恢复过程不重新下载、不生成随机楼群。

投影维持每米0.02场景单位，东西与南北方向使用同一比例。建筑挤出、楼层线、道路面宽、地形三角网与50米等高线直接复用早期几何实现，适配统一场景比例及当前材质接口。来源高度、按楼层估算和统一12米示意高度均按数据字段保留，未知高度不随机填充。

桌面与窄屏首次进入深圳湾；窄屏在相同中心拉近2.2倍，便于辨认建筑，桌面保留完整街区与海岸。全景按钮仍查看全深圳。区界继续使用上轮纠正后的龙岗与大鹏几何，旧版区界错误没有恢复。地图标签按屏幕像素保持字号并避碰。

8条已核路线直接投影全部原始点。每段使用分段直线，不以圆角或跨角线改变路线；断开的轨迹段始终分开。路线和骑友在画面上随地形高度显示，但GPX仍只保留真实经纬度，不把场景高程当作道路精确海拔或累计爬升。33条待核候选不绘制假轨迹。

当前恢复的数据范围与来源见[地图数据](地图数据.md)。实地通行限制、桥面高度与道路坡度不能仅凭场景推断。

## 模型与动态

立体地标保留春笋、春茧、平安金融中心、市民中心和京基一百的识别形态，继续使用原作 `Part` 和材质绘制。少量公路车骑手沿真实已核对路线运动；人物细节复用原作。动态骑手、时间和天气都是模拟。

真实普通建筑从轮廓挤出，地标保留可辨认的专用模型；地标模型是识别符号，其细节不代表测绘精度。先前抽象微缩组景保留为历史源码，不进入当前页面。

## 操作与回收

鼠标拖动平移，滚轮缩放。触屏单指平移，双指缩放与平移。悬停模型出现浮签，点击模型选择对象并显示详情；再次点击同一对象不改变状态。地点导航和全景按钮只移动镜头，保留已选对象。动态骑手支持跟随及方括号循环选择。手机与电脑共用路线选择、详情和轨迹导出。

组件卸载时取消动画、断开尺寸监听、销毁几何和文字纹理、清理原作文字材质登记、移除控制器事件。WebGL 上下文丢失时使用原作场景内提示，恢复后重新绘制。

在本地页面添加 `?debug=1` 可通过 `window.shenzhenMap.stats()` 读取模型数量、绘制次数和动画实体数量。统计还包含底图请求次数、加载分片、地形状态与JSON字节数；数据中的建筑面数量不等于官方建筑栋数。

## 新增摘取与模型

`models/port.ts` 原样复制，港吊使用原作 `buildSTS` 与 `staysPart`，货箱使用 `boxInto`。相关 `PORT`、`CURB` 与 `SEA_Z` 常量保持原值，仅服务模型自身尺寸。地标模块重新放置模型位置，不装配原作固定码头。

`world/ground.ts` 保留原作树、松树、棕榈、灯杆、长椅和圆环构造器。`world/town.ts` 保留 `windows`、`buildFlats`、`buildHouse` 和 `buildVilla` 的模型函数体。住宅与别墅移除了依赖工厂室内业务的 `userData.peek` 登记，外部模型、庭院、车库、篱笆和泳池细节保留。普通建筑标签传入中文。

`scene/landmarks.ts` 为深圳新增春笋、春茧、平安金融中心、市民中心、京基一百、深圳湾大桥和大梅沙地标。盐田港吊复用原模型，新增骑手复用原人物细节。这里的尺寸用于微缩艺术编排，不作为建筑测量资料。

## 性能与验收范围

动画采用原作的逐帧驱动，像素比上限2。暂停停止模拟时间，镜头与快进继续响应。编译与类型检查由队列执行，真实浏览器的画面与操作验证由主任务统一记录。

新增组景调用必须区分原作接口：`Part.poly`使用填充材质名（如`grass`），`Part.box`、`extrude`使用配色组合名（如`gs`）。原作模块保留`ts-nocheck`，因此类型检查不能替代真实浏览器的场景初始化检查。

## 原作界面与交互迁移

2026年10月8日按用户补充要求恢复原作页面外壳。`app/factory.css`与参考仓库的`app/globals.css`保持逐字相同；中文排版和骑行卡内新增控件单独放在`app/globals.css`。DM Mono字体文件从原作已构建资源原样复制，在本地加载。

`CyclingApp`沿用`YardFigure.tsx`的画框、题注、工具栏、浮签及详情卡结构和六个SVG。骑行路线与资料替换原作工厂业务，不增加常驻地图侧栏。题注恢复静态“图1”和时钟；顶部地点导航增加同款“路线”入口。对象卡保持head、title、status、bar、dl、foot六块，首层只展示关键字段和最多三个操作；完整资料放在同卡片的“更多”页面。

`engine.ts`从`yard/view.ts`迁移包围盒镜头适配、地点导航、平移缩放、鼠标点击判定、浮签定位、选择轮廓、地面四角框、路线虚线、跟随和快捷键。地标与活动模型挂接对象信息；水体合批几何通过实际地理位置解析对象。合批地面空白区域不作为地标。

时间从10:00开始，360秒为一个模拟日；快进每次增加六小时并按原作速度渐进。天气使用原作自动状态机与渐变，不提供另设的天气工具按钮。主题读取本地选择，没有本地选择时随系统；昼夜变化同步页面外围。减少动态偏好关闭镜头阻尼与过渡，不自动暂停模拟。

真实地图标注继续使用原作文字纹理和材质，面向镜头并按屏幕像素保持字号。全景显示区名，近景显示地标与河湖名；重叠时优先地标。背景道路保留面宽并使用原作细线描边，已核路线采用原作高亮配色的1.5像素半透明线，与原卡片的选中虚线区分。

## 菜单与字体严格对照（2026年10月10日）

`SelectionCard.tsx`保留上游对象卡的六块DOM、class、id和hidden规则，业务只提供字段与动作。场景的DOM顺序恢复为canvas、tools、三个浮签、card、note。跟随按钮保持固定文字，仅切换aria-pressed；地点与辅助菜单的选中状态互斥。骑行路线的文字和操作是内容适配，未加入工厂库存、车辆电量或不存在的室内功能。

四份DM Mono字体原字节保存在`public/fonts/`，正常体400/500及Latin、Latin Ext子集与上游构建资源一致，并补齐四项预载。`--mono`直接继承原`factory.css`，删除自行添加的中文字体优先级。地图构造前恢复上游500、64像素字体等待，最多2.5秒。中文内容仍使用上游链中的系统回退；本机同文探针两页均为拉丁字母及数字DM Mono、汉字苹方，不能将汉字说成DM Mono。

骑行表单使用原卡片数据行，控件继承同一字体、颜色和按钮圆角；额外样式仅用于表单宽度、长来源地址、无边框菜单动作及禁用状态。加载提示只接收重试按钮的点击，确保失败时仍可打开路线卡。文字长度、字段数量及汉字回退会改变内容宽高，未宣称不同中英文内容逐像素相同。
