# 深圳三维地图渲染说明

## 视觉来源

参考仓库为 [Factory](https://github.com/Khalidabdi1/factory)，参考版本为 `148758ae19a9b2201245485bf3619ab5e742f8f4`。

本项目直接保留原作可迁移的内核、材质和动态模型。微缩场景编排、深圳地标、示意路线与路线镜头是新增部分。镜头保持固定等角正交投影，面材质不受光照影响，轮廓线固定为 1 CSS 像素，镜头缓动沿用原参数。原作当前未提供明确的项目本体许可证，不能将整个 Factory 宣称为 MIT 项目。其 README 对 ai-iso-skill 与 Three.js 的 MIT 说明只适用于相应来源。当前实现用于本地开发，公开分发前须明确相关授权。

## 微缩场景与真实轨迹

根据最新方向，场景采用抽象、非等比例的手工编排。深圳湾为初始场景。春笋、春茧、人才公园、大桥与红树林构成骑行路线的空间参照。全城视图用地标串联南山、福田、罗湖、盐田、大鹏及北部湖区。普通街区、树木和山海按原作风格压缩表达，不表示逐栋真实地理复刻。

路线的真实经纬度独立保存在路线资料中。地图的示意路径保留已经核验路线的起终顺序、经过关系，以及开放或闭合状态。西丽东岸、梧桐绿道、淘金山和未闭合的石岩湖长线均使用开口线。示意路径不参与 GPX 导出，也不计算实际距离或爬升。待核路线只显示所在片区与锚点。

`scene/engine.ts` 与 `CityMap` 不下载城市、建筑分片或 DEM。旧版全量地理实现已保留在工作目录 `work/archive-geographic-scene/`，不在当前运行链路中。

## 模型与动态

汽车、行人、列车、船、雨线直接调用原作构造器。背景建筑直接调用原作 `buildFlats`，保留窗格、门、楼层线、屋顶设备与水箱。树木、棕榈、松树、灯杆和长椅从原作世界模块摘取。深圳地标与公路车模型使用原作 `Part` 和材质绘制。

场景中的交通、时间和天气均为演示，不表示实时车流、船期或天气预报。深圳湾大桥只提供地理背景，不作为可骑上桥的路线。

## 操作与回收

鼠标拖动平移，滚轮缩放。触屏单指平移，双指缩放与平移。点击地标名称可靠近查看，点击全城按钮可查看所有微缩片区。手机与电脑共用路线选择、详情和轨迹导出。

组件卸载时取消动画、断开尺寸与面板监听、销毁几何和文字纹理、清理原作文字材质登记、移除控制器事件。WebGL 不可用时显示中文错误与重新加载入口，路线册继续可用。

在本地页面添加 `?debug=1` 可通过 `window.shenzhenMap.stats()` 读取模型数量、绘制次数和动画实体数量。模型数量不表示深圳真实建筑或道路总数。

## 新增摘取与模型

`models/port.ts` 原样复制，港吊使用原作 `buildSTS` 与 `staysPart`，货箱使用 `boxInto`。相关 `PORT`、`CURB` 与 `SEA_Z` 常量保持原值，仅服务模型自身尺寸。地标模块重新放置模型位置，不装配原作固定码头。

`world/ground.ts` 保留原作树、松树、棕榈、灯杆、长椅和圆环构造器。`world/town.ts` 保留 `windows`、`buildFlats`、`buildHouse` 和 `buildVilla` 的模型函数体。住宅与别墅移除了依赖工厂室内业务的 `userData.peek` 登记，外部模型、庭院、车库、篱笆和泳池细节保留。普通建筑标签传入中文。

`scene/landmarks.ts` 为深圳新增春笋、春茧、平安金融中心、市民中心、京基一百、深圳湾大桥和大梅沙地标。盐田港吊复用原模型，新增骑手复用原人物细节。这里的尺寸用于微缩艺术编排，不作为建筑测量资料。

## 性能与验收范围

常规动态最多每秒绘制 30 帧，像素比上限 2。暂停时仅在镜头、天气、时间、主题或界面布局变化后重绘。编译与类型检查由队列执行，真实浏览器的画面与操作验证由主任务统一记录。

新增组景调用必须区分原作接口：`Part.poly`使用填充材质名（如`grass`），`Part.box`、`extrude`使用配色组合名（如`gs`）。原作模块保留`ts-nocheck`，因此类型检查不能替代真实浏览器的场景初始化检查。
