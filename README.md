# 深圳骑行地图

在深圳真实三维街区与山海之间，帮助公路车骑友在出发前选路线。

深圳海岸、街区、河湖、道路与山体采用真实地理数据。页面保留 Factory 的画框、灰阶细线与交互规则，恢复早期版本的建筑体量和地形层次。全城显示概览建筑，近景按视野加载详细街区。

## 本地运行

需要 Node.js 20.9 或更新版本。

```sh
npm install
npm run dev
```

打开 http://localhost:3701 。原作的 3700 端口保留作对照。仓库仅在本地，没有配置远端或公开发布。

```sh
npm run typecheck
npm run check:data
npm run build
```

构建输出为 `out/`，可以用普通静态服务器运行。

## 使用

界面沿用 Factory 的上下题注、顶部地点导航、左侧六个工具和对象详情卡。桌面与窄屏首屏均从深圳湾开始，全景按钮可查看全城。点击地点切换镜头，悬停模型显示名称，点击模型打开卡片；移动中的骑手可以跟随。

点击顶部“路线”，或地标卡中的“附近路线”，打开路线集。路线首层卡使用“查看、导出、更多”三个操作；通行条件、来源、分享与补给位于“更多”中，所有页面共用原作对象卡。

快捷键沿用原作：1 至 9、P、E、V、O、S 切换14处地点；0/Home 全景；加减号缩放；空格暂停；T 切换主题；N 快进六小时；F 跟随；方括号切换活动对象；Esc 关闭详情。天气自动变化。

41项资料包括33项全市候选和8条有真实连续坐标的路线。地图线路与导出轨迹使用同一份原始WGS84坐标，不跨段连线，也不为候选补画轨迹。

未知的爬升明确保留待核。未核对的路线禁止导出；工作日限定路线在选择周末与节假日时禁止导出。

分享按钮复制定位到同一路线的页面链接。本地地址不能供外网骑友直接访问，页面不会自动发布网站。功能不读取私人骑行记录或持续获取个人位置。

场景的天气、时间与骑手运动是视觉模拟。手机支持平移、缩放、路线详情、导出和分享。

## 组织

`app/` 是中文页面与样式；`components/` 是交互界面；`scene/` 是真实地理场景和原作复用模块；`lib/` 是路线与导出；`public/data/routes*.json` 和 `public/tracks/` 保存实际轨迹及证据；`scripts/` 保存提取与检查流程。

`public/data/shenzhen-city.json` 保存城市概览，`city-terrain.json` 保存按海岸裁切的地形，`tiles/` 保存按需加载的建筑和细路。来源与高度说明见[地图数据](docs/地图数据.md)。旧轻量底图仍保留作历史对照，当前页面使用恢复后的三维数据。

## 外卖专注体验原型

本地运行后访问：http://localhost:3701/prototype/delivery

- **核心玩法**：选择专注时长后，骑手自动在深圳取餐送单；收工后结算虚拟收入与评分，持续积累装备和城市足迹。
- **快速体验**：点击“90秒试跑”可体验完整的 45 分钟配送流程。试跑与正常专注使用相互独立的本地存档，互不干扰。
- **范围与说明**：本轮配送范围涵盖南山、前海及附近街区，订单与收入均为游戏模拟。完整规则、实现范围与实际验证见 [外卖专注原型](docs/外卖专注原型.md)。
