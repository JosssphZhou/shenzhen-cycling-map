# 深圳骑行地图

在深圳真实地理地图上，帮助公路车骑友在出发前选路线。

深圳海岸、河湖、道路、区界和骑行路线采用同一份地理坐标。页面保留 Factory 的画框、灰阶细线与交互规则；春笋等少量立体地标作为地图符号。底图经过制图简化，不加载整城建筑分片。

## 本地运行

需要 Node.js 20.9 或更新版本。

```sh
npm install
npm run dev
```

打开 http://localhost:3701 。原作的 3700 端口保留作对照。仓库仅在本地，没有配置远端或公开发布。

```sh
npm run typecheck
npm run check:data
npm run build
```

构建输出为 `out/`，可以用普通静态服务器运行。

## 使用

界面沿用 Factory 的上下题注、顶部地点导航、左侧六个工具和对象详情卡。桌面首屏为全城，窄屏首屏为深圳湾。点击地点切换镜头，悬停模型显示名称，点击模型打开卡片；移动中的骑手和车辆可以跟随。

点击题注上的骑行入口，或地标卡中的骑行路线动作，打开路线集。筛选、路面、通行条件、来源和轨迹操作均在同一张卡片中。

快捷键沿用原作：1 至 9、P、E、V、O、S 切换14处地点；0/Home 全景；加减号缩放；空格暂停；T 切换主题；N 快进六小时；F 跟随；方括号切换活动对象；Esc 关闭详情。天气自动变化。

41项资料包括33项全市候选和8条有真实连续坐标的路线。地图线路与导出轨迹使用同一份原始WGS84坐标，不跨段连线，也不为候选补画轨迹。

未知的爬升明确保留待核。未核对的路线禁止导出；工作日限定路线在选择周末与节假日时禁止导出。

分享按钮复制定位到同一路线的页面链接。本地地址不能供外网骑友直接访问，页面不会自动发布网站。功能不读取私人骑行记录或持续获取个人位置。

场景的天气、时间、交通和行人是视觉模拟。手机支持平移、缩放、路线详情、导出和分享。

## 组织

`app/` 是中文页面与样式；`components/` 是交互界面；`scene/` 是真实地理场景和原作复用模块；`lib/` 是路线与导出；`public/data/routes*.json` 和 `public/tracks/` 保存实际轨迹及证据；`scripts/` 保存提取与检查流程。

`public/data/shenzhen-map.json` 是从既有研究档案生成的轻量底图。原始全量数据保留在本任务 `work/` 中，不随前端交付。
