# 深圳骑行地图

用地标锚定的深圳微缩城市，帮助公路车骑友在出发前选路线。

春笋、春茧、平安金融中心等地标保留识别度；普通街区、山海与区际距离经过抽象和压缩。页面延续 Factory 的等角、灰阶、细线和小模型美感，不是一张等比例测绘地图。

## 本地运行

需要 Node.js 20.9 或更新版本。

```sh
npm install
npm run dev
```

打开 http://localhost:3701 。原作的 3700 端口保留作对照。仓库仅在本地，没有配置远端或公开发布。

```sh
npm run typecheck
npm run check:data
npm run build
```

构建输出为 `out/`，可以用普通静态服务器运行。

## 使用

首屏查看深圳湾微缩场景，通过地标与海岸认识路线关系。打开路线集后，可按地区、距离和爬升筛选，查看路面、通行条件与资料来源。

41项资料包括33项全市候选和8条有真实连续坐标的路线。屏幕中的路线经过简化；导出的轨迹独立使用开放地图原始WGS84坐标，不采用微缩坐标或动画圆角路径。

未知的爬升明确保留待核。未核对的路线禁止导出；工作日限定路线在选择周末与节假日时禁止导出。

分享按钮复制定位到同一路线的页面链接。本地地址不能供外网骑友直接访问，页面不会自动发布网站。功能不读取私人骑行记录或持续获取个人位置。

场景的天气、时间、交通和行人是视觉模拟。手机支持平移、缩放、路线详情、导出和分享。

## 组织

`app/` 是中文页面与样式；`components/` 是交互界面；`scene/` 是微缩场景和原作复用模块；`lib/` 是路线与导出；`public/data/routes*.json` 和 `public/tracks/` 保存实际轨迹及证据；`scripts/` 保存提取与检查流程。
